# Location-Based Android App (Kotlin)

This is an Android application developed using **Kotlin** that provides users with relevant information about their current location by fetching data from **Wikipedia**.

## 📱 Features
- Detects the user’s current location using **Google Location Services**
- Fetches and displays related information from the **Wikipedia API**
- Supports **Text-to-Speech (TTS)** to read the information aloud
- Uses **shake gesture detection** via device sensors to trigger voice playback
- Simple and user-friendly mobile interface

## 🛠 Technologies Used
- **Kotlin**
- **Android SDK**
- **Google Location / Maps API**
- **Wikipedia API**
- **Text-to-Speech (TTS)**
- **Device Sensors (Shake Detection)**

## 🚀 How It Works
1. The app retrieves the user’s current geographic location.
2. Based on the location, relevant Wikipedia content is fetched dynamically.
3. The information is displayed on the screen.
4. When the user shakes the phone, the displayed content is read aloud using text-to-speech.

## 🎯 Purpose
This project was developed as a mobile programming assignment to gain hands-on experience with:
- Android development using Kotlin  
- API integration  
- Location-based services  
- Sensor handling and accessibility features  

## 📌 Notes
- An active internet connection is required for fetching Wikipedia data.
- Location permissions must be granted for the app to function correctly.
